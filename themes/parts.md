# Theme parts (generated)

Every part a theme can target: `[data-part="name"]`, its states as words in `data-state` (select with
`[data-part="tracklist.row"][data-state~="active"]`). Generated from Voltage's code, so it is exact for the Voltage version
it came with. Promised like the plugin API: no part or state is removed or renamed in Voltage 1.x (new ones are only added).
`<name>` is filled in at run time (for example `tracklist.tab.queue`). Some parts also carry `data-view` (which variant or
page). How to use them: [THEMING.md](https://github.com/CastilloA27/Voltage-Plugins/blob/main/THEMING.md); tokens, variants,
labels and icons: [theme-reference.md](theme-reference.md).
