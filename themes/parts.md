# Theme parts (generated)

Every part a theme can target: `[data-part="name"]`, its states as words in `data-state` (select with
`[data-part="tracklist.row"][data-state~="active"]`). **Generated by `node tools/parts-list.mjs`** from the code; CI fails when
this file is out of date. Promised like the plugin API: no removal or rename in 1.x (docs/theming-v2.md 3.5). `<name>` is
filled in at runtime (for example `tracklist.tab.queue`). Some parts also carry `data-view` (which variant or page).
